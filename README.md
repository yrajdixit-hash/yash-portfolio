# Yash Raj Dixit - Personal Portfolio

A modern, high-performance personal portfolio website built with React, Three.js, GSAP, and Vite. Features interactive 3D visualizations, smooth inertial scrolling, terminal emulation, and responsive design.

## Features

- **Interactive 3D Visualizations**: Custom Three.js architectural and particle canvas viewers with smooth controls and camera transitions.
- **Micro-Interactions & Physics**: Magnetic buttons, 3D tilt cards, interactive terminal, and dynamic hover effects.
- **Smooth Scrolling**: Integrated Lenis smooth-scroll with GSAP-driven scroll animations.
- **Responsive Layout**: Designed for seamless experiences across desktop, tablet, and mobile devices.
- **Modern Architecture**: Fast builds and instant Hot Module Replacement (HMR) powered by Vite and React 19.

## Tech Stack

- **Frontend**: React 19, JavaScript (ES Modules), HTML5, CSS3
- **3D & Graphics**: Three.js
- **Animations**: GSAP (GreenSock), Lenis Scroll
- **Tooling & Build**: Vite, Oxlint

## Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yrajdixit-hash/yash-portfolio.git
   cd yash-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build locally:
   ```bash
   npm run preview
   ```
